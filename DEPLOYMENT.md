# Publishing

Repository: https://github.com/nutdnuy/the-magnificent-jump

Website: https://nutdnuy.github.io/the-magnificent-jump/

Push reviewed changes to `main`. The **Publish book** workflow installs locked dependencies, checks all 85 source blocks and the notebook, builds the four-page site and publishes `_site/` to GitHub Pages. This project has its own deployment and does not publish through Quantitative Finance Notes.

GitHub Pages uses GitHub Actions (`build_type: workflow`). No DNS or custom-domain configuration is required. After deployment, verify the landing page, all three chapters and the Notebook download.
